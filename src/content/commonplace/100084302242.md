Se la strade è di tutti, bisogna goderla / senza fare nient'altro, guardandosi intorno, / ora all'ombra ora al sole, nel fresco leggero. // Ogni via si spalanca che pare una porta, / ma nessuno l'infila.                    — If the street belongs to all, we should enjoy it / without doing anything else, looking around / now in shadow now in sunlight, in the fresh air. // And every path opens wide that seems like a door / but no one goes in.
from Cesare Pavese, “Atavismo”
